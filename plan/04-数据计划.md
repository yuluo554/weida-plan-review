# 04 数据计划

> 原则：**数据先行**。没有标注数据就程序化自制带真值数据（核心资产）；每份数据登记来源与许可（台账见 `data/README.md`）。

## 1. 数据四目录

| 目录 | 内容 | 来源 | 状态 |
| --- | --- | --- | --- |
| `data/samples/` | 专项方案样本（docx） | 程序化生成（`scripts/make_gold.py`） | ✅ 40 份 = 深基坑30 + 高支模10（M5，2026-09-27） |
| `data/intermediate/` | 解析中间格式样例（章节树/行文本/参数卡） | 生成器 + 解析器输出 | ⏳ M2 |
| `data/knowledge/` | raw 来源登记 / blocks 条文块 43 / thresholds 阈值表 41（深基坑25+高支模16） | 公开规范手工整理（全部待核对） | ✅ M4 打样 + M5 扩量（2026-09-27） |
| `data/gold/` | 配对真值：方案 docx + truth.json（参数真值 + 注入差异 80 处 + also_expect） | 生成器 | ✅ M4 60 处 → M5 80 处（2026-09-27） |

**红线**：真实项目材料（含单位名/人员/项目名的 docx/pdf）一律不进仓库；本地私料放 `data/**/_private/`（已 gitignore）。

## 2. 配对真值生成器设计（`scripts/make_gold.py`，M1–M2 实现）

- **模板 + 随机参数**：深基坑/高支模方案模板（含 31 号文要求的主要章节），按合理范围随机抽参数（深度 4–9m、位移控制 20–40mm、监测频率 0.5–2 次/d……）
- **注入已知差异**（真值随之记录，用于端到端评测）：
  - 漏章节：删掉"应急处置措施"
  - 超阈值：位移控制值取 35mm（>30mm）
  - 频率不足：监测频率 0.5 次/d（<1）
  - 单位错误：5.4 写成 54（物理范围校验应丢弃并标 manual）
  - 多值冲突：正文与计算书给出两个不同位移控制值
- **输出**：`samples/gen_XXXX.docx` + `gold/gen_XXXX.truth.json`（每张参数卡真值 + 每处注入差异的期望结论）；M5 起高支模文件名前缀 `fs_XXXX`（`--fs-count` 控制，默认 10）
- **规模目标（M4 前）**：样例方案 ≥30 份（深基坑 20 + 高支模 10），注入差异 ≥60 处
- **M4 落地与偏差**（2026-09-27）：30 份 = **深基坑先行**（高支模模板+规则随 M5），注入 60 处；
  基准不变量 = 自然参数不触发任何非 pass 结论（自然监测频率固定 ≥2 次/d，避开建议规则 R-DP-061）；
  **真值口径**：每处注入 `expect` 记主期望、`also_expect` 记同一注入隐含的其余非 pass 结论
  （多值冲突使其参数上全部规则输出 manual——low_freq → R-DP-031+R-DP-061 fail、
  multi_disp → R-DP-021/022/062/073 manual），评测按"文档全部非 pass 集合"对账
- **M5 落地**（2026-09-27）：高支模模板 `make_fs_spec`（自然高度 5.5–7.5m / 立杆间距 0.8–1.1m /
  支撑类型 4 选 1）+ 注入 5 类（over_height/low_spacing/multi_height/unit_error/missing_section），
  语料扩到 **40 份 / 注入 80 处**；高支模阈值经建办质〔2018〕31号 附件1/2 检索核实（危大 ≥5m/
  10kN/m²/15kN/m，超规模 ≥8m/18m/15kN/m²/20kN/m，入库仍标待核对）。踩坑三条已修：
  ① fs.formwork.type 真值存提取器捕获的短名（"扣件式"）；② unit_error 改打立杆间距
  （原与 multi_height 同参数互斥冲突）；③ over_height 注入前移除计算书高度行（防组合误触发
  R-FS-101）；类目隔离靠规则 only_if_text 门控（引擎已修复为对全部 check_type 生效）

## 4. 许可与合规台账

- 法规条文：公开政府文件，整理时注明出处与"以官方文本为准"，不全文转载规范出版社受版权保护的版本（用条款要点+出处引用形式）
- 自制数据：MIT 随仓库发布，无第三方权利问题
- 登记载体：`data/README.md` 台账表，新增数据必须先登记后入库
